# RAMSOTEC Knowledge

**Local Enterprise AI | Industrial Intelligence**

Plataforma de inteligencia artificial empresarial local y multimodal, orientada a transformar documentación técnica y organizacional en conocimiento accesible, verificable y seguro.

**Estado del proyecto:** Prototipo funcional en desarrollo.

## Descripción

RAMSOTEC Knowledge es un proyecto de software que combina modelos de lenguaje ejecutados localmente, recuperación aumentada por generación (RAG), búsqueda semántica y mecanismos de validación documental.

Su objetivo es permitir que trabajadores consulten información empresarial mediante lenguaje natural, con especial atención a técnicos de mantenimiento y operaciones industriales.

## Tecnologías utilizadas

- Python
- Ollama
- Llama 3.2 (3B)
- Qwen2.5-VL (3B)
- Nomic Embed Text
- Streamlit
- Arquitectura RAG híbrida
- Búsqueda semántica y validación documental

## Funcionalidades implementadas y probadas

- Ejecución local de modelos de inteligencia artificial.
- Recuperación de información desde documentos técnicos.
- Consulta y validación de códigos SAP.
- Detección y bloqueo de respuestas ante conflictos documentales específicos.
- Recuperación de procedimientos técnicos documentados.
- Interfaz web de consulta con visualización de evidencias.
- Pruebas iniciales de interpretación de imágenes con un modelo de visión local.

## Funcionalidades en desarrollo

- Integración de imágenes con el motor documental.
- Consultas mediante audio y video.
- Arquitectura centralizada en servidores empresariales.
- Acceso desde dispositivos móviles.
- Gestión de usuarios, departamentos y permisos.
- Conexión controlada a fuentes externas de internet.
- Escalabilidad para múltiples usuarios y grandes volúmenes documentales.

## Aplicaciones previstas

- Mantenimiento industrial y asistencia técnica.
- Gestión de documentación.

## Seguridad y privacidad

El proyecto sigue una estrategia de procesamiento local, validación de evidencias y separación de funciones.

Las capacidades empresariales de autenticación, autorización y aislamiento documental se encuentran en desarrollo.

El repositorio presenta documentación y resultados de un prototipo local. El código del motor principal no se publica en esta etapa.

Las imágenes y los manuales de laboratorio utilizan equipos y datos ficticios.
